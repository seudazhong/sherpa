Models

配置你自己的模型来源。每个来源 = 一个 provider 端点 + 一把密钥 + 可用 model 列表。选一个全局默认；每个对话也能单独切换。密钥只在服务端加密保存、绝不回显。

⚠️ 设计与契约先行稿（ADR-041）。此为静态设计稿，功能尚未实现、无迁移、无生产代码。 密钥 AEAD 加密存 DB（复用 github_token.py 的 KEK 直封）， 仅在 Provider.stream() 边界解密，绝不进日志/事件/prompt/工具输出/前端。 provider 配置是人工设置，不给 agent（跨凭据边界，同 GitHub 连接）。
◈
全局默认： OpenAI · gpt-5.1。没配置任何来源时回退到 env PROVIDER_*（离线/mock）。跨-provider failover、成本 ledger、子 agent 为后续里程碑（各自 ADR）。

添加来源

「测试连接」在服务端用密钥拉该来源的 /models（或发一次极小 chat）；成功 → active + 填充 model 列表，失败 → 记录脱敏错误。

对话里切换 model

除全局默认外，每个对话可单独切换来源 / model；切换持久化到该会话（携带来源引用，避免用到旧端点/协议）。
