# Session Library static prototype

Static HTML product design for [R-SESSION-SEARCH](../research/session-search.md), based on the recommendation in [`session-search-report.md`](../research/session-search-report.md).

Open [`index.html`](index.html) directly in a browser. The prototype is self-contained and makes no API calls.

It demonstrates:

- recent-session browsing and content search;
- channel/status filters;
- session-grouped match snippets;
- exact-turn preview;
- distinct Resume, Reconnect, Review approval, and Resolve outcome actions;
- responsive desktop and mobile layouts.

This is a product design artifact only. It does not change the production frontend.
