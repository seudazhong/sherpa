single-writer lease + fence。 一个工作副本一个活动写者租约；每个执行盖单调 fence_token。stale 沙箱（fence 落后）绝不能发布 overlay，即使重投递让其租约看似 live。同一 Project 的多个 Chat 得到互相隔离的工作副本，彼此看不到也改不到对方的 pending 态。

真相源层级 · 隔离边界
系统维护的是任务工作副本，不是某个容器。
  • 1Project head 快照
    持久 · 已保存 · 用户可见的真相源（Postgres + 不可变去重 blob）    authoritative
  • 2任务工作副本 overlay
    durable pending 态 · 跨 chat turn 的持久任务态（overlay 表 + blob 引用）    authoritative
  • 3Scratch 卷
    节点本地一次性拷贝 · 每次执行物化 · 随时可丢/可重建    rebuildable cache
  • 4Sandbox 容器
    短 TTL 进程边界 · 可选热态 · 随时可杀 · 对正确性/恢复从不必需    ephemeral

沙箱挂载边界（ADR-039 / 修订版 ADR-025）

  • 仅挂：一份一次性 scratch 拷贝（RW · nosuid,nodev）
  • 绝不挂：Project 快照 / storage_blobs·MinIO
  • 绝不挂：其它 Project / 工作副本 / Drive
  • 绝不挂：WORKSPACE_ROOT / TOOL_OUTPUT_ROOT / 溢出路径
  • 绝不注入：任何 model / provider / storage / GitHub / KEK 凭据
  • 绝不接触：docker.sock（只在可信编排进程）
保留全部 ADR-025 硬化：断网 · cap_drop ALL · no-new-privileges · 非 root · 只读 rootfs + tmpfs · mem/pids/cpu/墙钟上限 · --rm。拷贝前剔除/断言无凭据；编排 finally 原子清理 + 启动扫除孤儿 scratch。
