选择一个起点

项目是持久的 Sherpa 状态。W2a 提供三条创建路径。
Z

上传归档

安全检查并解压 ZIP / TAR，生成一个新的、无源的项目初始快照。

B

空项目

从一棵空的持久树开始，随后再添加内容。

T

使用模板

拷贝模板内容，但不保留模板仓库的历史。

W2b G

从 GitHub 导入

一次性导入分支头为初始快照并记录源绑定。W2a 不含，放在 W2b（另立 ADR）。

归档导入

上传并展开一个归档

无源 · unbound
拖拽 .zip / .tar.gz 到此，或点击选择 · 服务端生成对象键，不信任扩展名 / Content-Type
预留容量解压前先按上限预留，验证后释放未用部分。 ≤ 200 MiB
隔离 staging + 有界解压。 强制大小 / 文件数 / 膨胀比 / 嵌套深度上限（PROJECT_MAX_*）；拒绝绝对 / 穿越（..）路径、设备、FIFO、硬链接、逃逸 symlink。验证通过才写入不可变快照。凭据永不进项目树。

「空项目 / 模板」是单事务创建（无 staging），立即产出初始 import 快照。「归档导入」返回 202，状态从预快照开始，导入完成后原子激活。
