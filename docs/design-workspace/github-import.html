GitHub 一次性导入

选择一个 GitHub 仓库与 ref（分支 / 标签 / 提交），Sherpa 有界拉取该 ref 的内容树（不含 git 历史），记录来源 repo/ref/OID，物化为项目的不可变初始快照。导入后项目独立存活——远端不是权威源。

⚠️ 设计与契约先行稿（ADR-038 · W2b） 此为静态设计稿，功能尚未实现、W2b 生产入口/导航未暴露。请勿当作已上线行为。W2b = GitHub 一次性导入（只读）；工作副本 + 沙箱 = W3；GitHub 同步 / push / PR = W4（各自后续 ADR）。
GET / POST / DELETE /connections/github

GitHub 凭据只保存在 AEAD 加密的 vault（复用 connector/credential 边界），仅由导入 worker 在服务端解密使用，绝不进入项目树 / 快照 / prompt / 日志 / 工具结果 / 沙箱。
